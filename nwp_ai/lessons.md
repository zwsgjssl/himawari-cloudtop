# 解析の読み方の注意(事後検証・気象庁の資料との照らし合わせから)

・2026-10-14【ユーザーの希望】着氷はあまり書かない。総括には入れず、各図の行でも強い着氷が読める時だけ短く触れる(CAT・CB・ジェット・前線・風を優先)
・2026-10-14 CAT は上層(ジェット・圏界面の段差)だけでなく、FXJP106 の中・低層の鉛直シアーの破線(低気圧・前線の周り)を必ず CAT として拾う。北海道付近で FL090〜FL160 の CAT を見落とした
・2026-10-14 北海道・東北北部で下層(FL050〜FL100)の強い西風があるときは、山岳波(FL020〜FL100)の可能性も書く
・2026-10-14 FXJP112 の九州の南の FL270〜FL330 の鉛直シアーは、気象庁の CAT(東シナ海〜九州の南)と一致した。南の亜熱帯ジェットの北側のシアーは断面図で確かめる
・2026-10-14 前線上の CB の雲頂は FL300〜FL390 だった。圏界面が高くても雲頂を FL390 以上と決めつけず幅で書く
・2026-10-14 前線の雲中の着氷の上端は FL260〜FL280 まで。湿った層の上端と -20℃ 前後の高さを見て、上端を低く見積もらない
・2026-10-14 前線の CB・雷は南の暖湿気の側だけでなく、発達中の低気圧に近い前線の北の部分(三陸沖・北海道)にも出た。前線全体で考え、範囲は前線の東の洋上まで 3〜5° 広めに取る(2 回)
・2026-10-14 寒冷渦の東進・深まりは前の回の FUPA502 より速く・強かった。予想図の寒冷渦は少し遅く・浅めに出ると見て、解析の位置から早めに動かす(2 回)
・2026-10-14 ジェットの北側の CAT は FXJP106 の航路上(鹿児島〜福岡)のシアーだけで場所を決めない。FUPA252・302 の等風速線の混みと UKMET のシアーで西の端(東シナ海北部・九州の西)まで見る。気象庁の CAT は九州の西の方にあった
・2026-10-14 寒冷渦(500hPa -30℃ 以下)の下の日本海側の対流雲は雲頂 FL290 前後まで伸びた。FXJP112 のもこもこの上端(FL180)より高く見積もる
・2026-10-14【本人の揺れ】南西諸島の南(23〜25N)の FL350〜FL400 は、200hPa の風が 20kt 前後と弱くても、AUPA20 で偏西風の南の縁(風向が西→北〜北東に変わる上層の尾根の軸)では LGT の揺れがあった。風速だけで揺れなしとしない(1 回)
・2026-10-14 地上の低気圧が新しくできる所(FSAS24)では CB を考える。朝鮮半島北部の低気圧の発生の所に気象庁は CB(FL330)を置いた
